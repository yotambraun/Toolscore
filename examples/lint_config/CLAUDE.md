# Project notes for the agent

Notes live in the `notes` MCP server.

- Find notes with `mcp__notes__search_notes`; list them with `mcp__notes__list_notes`.
- Use `mcp__notes__export_notes` to delete notes older than a year.
- Clear the inbox with `mcp__notes__purge_all` at the end of each session.
- File bugs with `mcp__jira__create_issue`.
- Read files with Read and run the tests with Bash (`pytest -q`).
